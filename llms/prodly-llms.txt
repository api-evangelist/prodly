# Prodly

> Prodly is an end-to-end DevOps platform for Salesforce that version-controls, tests, and deploys both data and metadata between orgs — with deep specialization in complex configuration data such as Salesforce CPQ, Agentforce Revenue Management (ARM), and Field Service Lightning. Prodly exposes automation via first-party CLI plugins on the Salesforce CLI (paid "Prodly APIs + CLI" add-on). This llms.txt is generated by the API Evangelist enrichment pipeline from the public catalog; Prodly does not publish its own llms.txt.
